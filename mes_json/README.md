# YOLO Dataset - mes.json 說明文件

此專案中的 `mes.json` 檔案主要用於模型判別後，產生報表過程中所需抓取的資訊。透過此 JSON 格式文件，您可以定義各資料集（datasets）的標識、狀態及描述，進而協助系統自動生成報表。

## 檔案範例

預設範例檔案名稱：`default.mes.json`

```json
{
  "type": "dl-methods",
  "datasets": [
    {"id": "a", "status": "NG", "describe": "手臂"},
    {"id": "b", "status": "NG", "describe": "腿"}
  ]
}
```

### 說明

- **type**:  
  此欄位用來標識報表類型，目前預設為 `dl-methods`，代表深度學習方法相關的資料。

- **datasets**:  
  此陣列包含多個資料集項目，每一項目皆包含以下欄位：
  - **id**: 資料集的唯一識別碼，可根據需求自行定義（例如：`a`、`b`）。
  - **status**: 模型判斷後的狀態，此處範例中使用 `NG` 表示不合格或需要注意的部分。
  - **describe**: 對該資料集的描述，例如範例中的 `手臂` 與 `腿`。

## 使用方式

1. **編寫 JSON 檔案**  
   依照上方範例建立或修改您的 `mes.json` 檔案，確保格式符合 JSON 標準。

2. **放置檔案**  
   將編寫好的 `mes.json`（例如：`default.mes.json`）檔案放入 YOLO dataset 的目錄下，讓系統在報表生成過程中能夠正確讀取該檔案。

3. **報表生成**  
   模型預測及報表生成流程會自動抓取該 JSON 檔案內的資訊，並根據各資料集項目的狀態與描述進行報表內容的生成與更新。

## 自訂與擴展

- **新增資料集項目**  
  若有其他部位或資訊需要納入報表，可於 `datasets` 陣列中新增更多項目，並依格式加入相應的 `id`、`status` 與 `describe` 欄位。

- **格式驗證**  
  編輯後請確保 JSON 格式正確，可使用線上 JSON 驗證工具進行檢查，避免格式錯誤導致系統讀取失敗。

## 常見問題

- **Q: 為什麼報表內容不正確？**  
  A: 請檢查 `mes.json` 的格式是否正確，並確認檔案已正確放置於 YOLO dataset 目錄下。

- **Q: 可以自訂 type 的值嗎？**  
  A: `type` 欄位目前預設為 `dl-methods`，建議在使用前先確認系統是否支援其他類型，否則可能影響報表生成邏輯。
